# Калькулятор

Браузерный калькулятор со скобками, клавиатурным вводом и историей вычислений. Работает на HTML, CSS и JavaScript без сборки и сетевых зависимостей.

## Запуск

Откройте `index.html` в браузере. Для локального сервера можно запустить `python3 -m http.server 8000` в папке проекта.

## Управление

- Цифры, `+`, `-`, `*`, `/` и скобки можно вводить на экране или с клавиатуры.
- Точка и запятая с клавиатуры служат десятичным разделителем.
- `Enter` или `=` вычисляют результат, `Backspace` удаляет символ, `Esc` очищает выражение.
- Выберите запись истории, чтобы использовать её результат в следующем вычислении. История текущей страницы хранит последние 30 записей.

Выражения разбираются как арифметика. Калькулятор учитывает приоритет операций, знаки и скобки. При делении на ноль и незавершённом вводе исходное выражение остаётся на экране для исправления.
